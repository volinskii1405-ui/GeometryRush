# Geometry Rush

2D ритм-раннер на C++17 и [raylib](https://www.raylib.com/) 5.5. Вдохновлён Geometry Dash,
но со своим оформлением: вся графика (иконки, блоки, порталы, фон) рисуется процедурно
примитивами raylib, внешних картинок нет.

В репозитории также есть 3D-авиасимулятор **Flight Sim** — см. [раздел ниже](#flight-sim--3d-симулятор-самолёта).

## Сборка

Нужны CMake ≥ 3.16, компилятор с C++17 и git (raylib скачивается через `FetchContent`).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j
./build/GeometryRush            # Windows: build\Release\GeometryRush.exe
```

* **Linux:** для GLFW нужны dev-пакеты X11/OpenGL, например на Ubuntu/Debian:
  `sudo apt install libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libgl1-mesa-dev`
* **Windows:** Visual Studio 2019+ (генератор по умолчанию) или MinGW-w64.

После сборки папка `levels/` копируется рядом с исполняемым файлом. Там же создаётся
`settings.txt` с выбранными иконками, цветами и рекордами.

## Управление

| Действие | Клавиши |
|---|---|
| Прыжок / переворот / подъём | `Space`, `↑`, `W`, левая кнопка мыши |
| Пауза / продолжить | `Esc` (или `P`) |
| Быстрый рестарт | `R` |
| Меню | стрелки/`W`/`S` — выбор, `Enter` — подтвердить, `Esc` — назад |
| Экран иконок | `1`/`2`/`3` или `Tab` — режим, стрелки — иконка, `T` — след |

| # | Уровень | Сложность | Что внутри |
|---|---|---|---|
| 1 | Neon Steps | Easy | знакомство со всеми тремя режимами |
| 2 | Gravity Forge | Normal | бег куба по потолку, узкий коридор корабля |
| 3 | Crystal Cavern | Normal | лестница из платформ над шипами, пещера для корабля |
| 4 | Pulse Reactor | Hard | длинная секция шара, перевёрнутый куб, ворота корабля |

## Редактор уровней

Главное меню → **EDITOR**. Там список своих уровней (**NEW**, **EDIT**, **DELETE**). Свои уровни
сохраняются в папку `mylevels/` рядом с игрой и появляются в **PLAY** с пометкой CUSTOM.

| Действие | Управление |
|---|---|
| Рисовать / стирать | ЛКМ / ПКМ |
| Инструменты | `1`–`0` или `Q`/`E`: блок, шип, шип вниз, порталы куба/шара/корабля/гравитации/нормальной гравитации, финиш, ластик |
| Прокрутка | `A`/`D`, стрелки (`Shift` — быстрее), колесо мыши, зажатое колесо; `Home`/`End` |
| Отмена | `Ctrl+Z` |
| Сохранить | `Ctrl+S` или кнопка SAVE (при тесте и выходе сохраняется автоматически) |
| Тест-плей | `F5` / `Enter` / кнопка TEST; в тесте `Esc` возвращает в редактор |
| Тема (цвета) | `T` / кнопка THEME |
| Название | клик по полю с именем |

Пунктирная розовая линия — потолок коридора корабля/шара. Уровень сохраняется в том же текстовом
формате, что и официальные, так что его можно дописать вручную.

### Режимы

Гравитация мягкая, как в Geometry Dash: прыжок куба ~2.2 клетки в высоту и ~0.46 с в воздухе
(~4.8 клетки по горизонтали). Все значения — в `src/config.h`.

* **Куб** — прыжок только с поверхности; удержание кнопки = автопрыжок при приземлении.
  В воздухе куб вращается, на земле угол доводится до ближайших 90°.
* **Шар** — нажатие на поверхности инвертирует гравитацию, шар перекатывается на потолок и обратно.
* **Корабль** — удержание = ускорение вверх, отпускание = вниз; вертикальная скорость ограничена,
  корпус наклоняется по скорости. Показываются пол и потолок коридора.

Смерть — касание шипа или удар боковой гранью блока (куб и шар также погибают при ударе
«головой» о низ блока; корабль скользит). На верхнюю грань можно приземляться.

## Структура кода

```
src/
  main.cpp          точка входа
  config.h          enum PlayerMode и все константы физики/камеры — крутите здесь
  Game.h/.cpp       машина состояний, цикл с фиксированным шагом 240 Гц, рендер мира, HUD, частицы
  Player.h/.cpp     физика куба, шара и корабля
  Level.h/.cpp      загрузка текстового уровня, порталы, отрисовка объектов
  Collision.h/.cpp  хитбоксы и запросы к сетке
  IconRenderer.*    8 кубов, 8 шаров, 8 кораблей (каждая иконка — своя функция) и палитра из 12 цветов
  Editor.*          встроенный редактор уровней
  Menu.*, UI.*      экраны меню и простые виджеты
  Settings.*        settings.txt (key=value)
tools/level_check.cpp  консольный решатель: проверяет, что уровень проходим
levels/             уровни
```

Физика идёт фиксированными шагами (`cfg::PHYSICS_HZ = 240`) через аккумулятор, рендер
интерполирует позицию между шагами, так что поведение не зависит от FPS.

## Как создать свой уровень

Положите `.txt`-файл в `levels/` — он появится в меню выбора уровня (сортировка по имени файла;
имя файла без расширения — ключ рекорда в `settings.txt`).

```
// комментарий
@name My Level        название в меню
@difficulty Hard      метка сложности: Easy / Normal / Hard / Insane (необязательно)
@bg 40 90 200         цвет фона (RGB)
@ground 30 70 170     цвет пола/блоков
................................................
..........................................#.....
.......^.......###.....^^.....S.....#.....#...E.
```

| Символ | Объект |
|---|---|
| `.` или пробел | пусто |
| `#` | блок (на верх можно встать, бок убивает) |
| `^` / `v` | шип вверх / шип вниз (висит на верхней грани клетки) |
| `C` `B` `S` | порталы куба, шара, корабля |
| `G` | портал инверсии гравитации (переключает) |
| `N` | портал нормальной гравитации |
| `E` | финиш (по X самой левой `E`) |

Правила сетки:

* Клетка — 40×40 px. Последняя строка стоит на полу; пол есть всегда.
* Игрок стартует в колонке 2 на полу и едет вправо со скоростью ~10.4 клетки/с.
  Прыжок куба — ~2.2 клетки в высоту и ~4.8 клетки в длину.
* Коридор корабля/шара (а также перевёрнутого куба) — 10 клеток над полом. В уровне из
  12 строк это строки 2–11; потолок — верхняя грань строки 2.
* Портал из одной буквы занимает 3 клетки по высоте (свою и по одной сверху/снизу).
  Несколько одинаковых букв друг под другом сливаются в один высокий портал — удобно, чтобы
  игрок не «промахнулся» мимо портала в коридоре (`C` в строках 3–10 закрывает весь коридор).
* Каждый портал срабатывает один раз за попытку.

### Проверка проходимости

```bash
cmake -S . -B build -DGEOMETRY_RUSH_BUILD_TOOLS=ON
cmake --build build --target level_check
./build/level_check levels/*.txt          # --path выведет найденную последовательность нажатий
```

`level_check` перебирает все варианты «держать/отпустить» с шагом 1/60 с и 1/30 с на той же
физике, что и игра, и сообщает, проходим ли уровень, а также насколько далеко уходят
тривиальные стратегии («ничего не нажимать», «всё время держать»).

# Flight Sim — 3D-симулятор самолёта

В том же репозитории есть второй исполняемый файл — **`FlightSim`**: 3D-авиасимулятор с физикой,
близкой к реальной, тремя самолётами, заданиями со звёздами, погодой, ночью и отказами.
Интерфейс на русском (переключается на английский в настройках). Собирается той же командой, что и игра:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j
./build/FlightSim               # Windows: build\Release\FlightSim.exe
```

Рядом с программой должны лежать папки `fonts/` (шрифт DejaVu Sans с кириллицей) и `sounds/`
(голосовые сигналы) — CMake копирует их при сборке.

## Самолёты

| Самолёт | Масса | Отрыв / заход | Особенности |
|---|---|---|---|
| Бизнес-джет | 7.6 т | ~110 / ~120 kt | два двигателя на хвосте, Т-образное оперение, реверс |
| «Сессна» (C172) | 1 т | ~55 / ~65 kt | винт, неубирающееся шасси, высокоплан — самый простой |
| Лайнер класса A320 | 60 т | ~140 / ~140 kt | двигатели под крылом, инертный, реверс, автомат тяги |

Физика с 6 степенями свободы: сваливание и штопор, влияние земли, волновой кризис, рули с конечной
скоростью отклонения, триммер, шасси с амортизаторами и носовым колесом, тормоза, **реверс тяги**.
Каждый двигатель отдельно: несимметричная тяга при отказе разворачивает самолёт.
**Топливо** расходуется по режиму, масса самолёта меняется; без топлива двигатели останавливаются.

## Задания (14)

Первый взлёт · Круг на «Сессне» · Заход по ILS · Боковой ветер · Ночная посадка · Туман ·
Отказ двигателя на взлёте · Пожар двигателя · Шасси не выпускается · Горная трасса (10 ворот) ·
Горный аэродром · Без топлива · Лайнер под дождём · Посадка без закрылков.

Звёзды: первая — за выполнение, вторая и третья — за точность (мягкое касание, ось полосы и зона
приземления, время, без предупреждений). Рекорды сохраняются в `flightsim.cfg` рядом с программой.

## Свободный полёт

Выбирается самолёт, аэродром, старт (на полосе, на заходе, в воздухе), время суток (день, закат, ночь),
погода (ясно, кучевые облака, сплошная облачность, дождь, туман), ветер, топливо и **случайные отказы**.

## Мир

* Остров 41×41 км: горы, леса (~45 тыс. деревьев), три города с домами, дорогами и фонарями.
* **Аэропорт «Остров»** — ВПП 09/27, 2600 м, ILS на оба курса, огни приближения, PAPI.
* **Горный аэродром «Перевал»** — ВПП 16/34, 1200 м на краю обрыва, высота 480 м, без ILS, только
  PAPI и глиссада 3.5°. Садиться — на 16 (с другой стороны хребет).
* Ночь: звёзды, огни полос и города, посадочные фары освещают землю. Закат — оранжевое небо.
* Облака: кучевые, сплошной слой (внутри — белая мгла, над ним — солнце), туман, дождь с каплями на стекле.
* Дым из-под колёс при касании, выхлоп двигателей, дым и огонь горящего двигателя.

## Отказы

| Отказ | Что делать |
|---|---|
| Двигатель | держать курс педалями (`Q`/`E`), лететь на втором |
| Пожар двигателя (ENGINE FIRE, звонок) | `J` — пожарный кран: выключить двигатель и потушить |
| Отказ гидросистемы шасси (GEAR UNSAFE) | `H` — аварийный выпуск под собственным весом, ~15 с |
| Закрылки заклинило | заход на скорости на ~20 kt выше |
| Утечка / нехватка топлива | садиться на ближайший аэродром или планировать |

Справа на панели — список отказов с подсказкой, что делать (как экран ECAM).

## Автопилот и директор

| Клавиша | Действие |
|---|---|
| `T` | автопилот (AP) вкл/выкл — только в воздухе выше 100 ft |
| `Y` | автомат тяги (A/THR) — держит заданную скорость, на 30 ft убирает газ (RETARD) |
| `L` | заход по ILS: захват курса (LOC) и глиссады (G/S); на 150 ft AP отключается — садитесь сами |
| `U` | режим V/S: набор/снижение с заданной вертикальной скоростью до заданной высоты |
| `X` в воздухе | **TO/GA** — уход на второй круг: взлётный режим, нос 12.5°, набор высоты |
| `O` | командный прибор (Flight Director) — пурпурное перекрестие на авиагоризонте |
| `9`/`0` · `-`/`=` · `,`/`.` · `;`/`'` | курс · высота · скорость · вертикальная скорость |

Строка режимов над приборами: `A/THR SPEED | HDG / LOC | ALT / G/S / V/S / GA / TO | AP FD`.

## Отсчёт высоты и сигнализация

На снижении с выпущенным шасси: **1000, 500, MINIMUMS (200), 100, 50, 40, 30, 20, 10, RETARD**.

| Сигнал | Когда |
|---|---|
| **PULL UP! TERRAIN** | столкновение с рельефом по курсу меньше чем через 18 с (10 с на заходе) или опасная вертикальная скорость |
| **TERRAIN** | столкновение по курсу через ≤ 35 с |
| **OVERSPEED** | выше ограничения: Vmo, Vfe для закрылков, Vle для шасси |
| **BANK ANGLE** | крен больше 35° |
| **STALL** | угол атаки близко к критическому (тряска штурвала) |
| **SINK RATE**, **TOO LOW – GEAR** | быстрое снижение у земли, шасси не выпущено |
| **ENGINE FIRE / FAIL**, **GEAR UNSAFE**, **FLAPS JAMMED**, **FUEL LOW** | отказы систем |

Голоса берутся из `sounds/`: `pull_up.ogg`, `terrain.ogg`, `sink_rate.ogg`, `too_low_gear.ogg`,
`bank_angle.ogg`, `overspeed.ogg`, `stall.ogg`, `callout_1000.ogg`, `callout_500.ogg`, `minimums.ogg`,
`callout_100.ogg`, `callout_50.ogg` … `callout_10.ogg`, `retard.ogg`, `ap_disconnect.ogg`
(WAV/OGG/MP3, имя с расширением `.ogg`). Если файла нет — звучит синтезированный тон.
