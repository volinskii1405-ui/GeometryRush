# Geometry Rush

2D ритм-раннер на C++17 и [raylib](https://www.raylib.com/) 5.5. Вдохновлён Geometry Dash,
но со своим оформлением: вся графика (иконки, блоки, порталы, фон) рисуется процедурно
примитивами raylib, внешних картинок нет.

В репозитории также есть 3D-авиасимулятор **Flight Sim** — см. [раздел ниже](#flight-sim--3d-симулятор-самолёта).

## Сборка

Нужны CMake ≥ 3.16, компилятор с C++17 и git (raylib скачивается через `FetchContent`).

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j
./build/GeometryRush            # Windows: build\Release\GeometryRush.exe
```

* **Linux:** для GLFW нужны dev-пакеты X11/OpenGL, например на Ubuntu/Debian:
  `sudo apt install libx11-dev libxrandr-dev libxinerama-dev libxcursor-dev libxi-dev libgl1-mesa-dev`
* **Windows:** Visual Studio 2019+ (генератор по умолчанию) или MinGW-w64.

После сборки папка `levels/` копируется рядом с исполняемым файлом. Там же создаётся
`settings.txt` с выбранными иконками, цветами и рекордами.

## Управление

| Действие | Клавиши |
|---|---|
| Прыжок / переворот / подъём | `Space`, `↑`, `W`, левая кнопка мыши |
| Пауза / продолжить | `Esc` (или `P`) |
| Быстрый рестарт | `R` |
| Меню | стрелки/`W`/`S` — выбор, `Enter` — подтвердить, `Esc` — назад |
| Экран иконок | `1`/`2`/`3` или `Tab` — режим, стрелки — иконка, `T` — след |

## Уровни

| # | Уровень | Сложность | Что внутри |
|---|---|---|---|
| 1 | Neon Steps | Easy | знакомство со всеми тремя режимами |
| 2 | Gravity Forge | Normal | бег куба по потолку, узкий коридор корабля |
| 3 | Crystal Cavern | Normal | лестница из платформ над шипами, пещера для корабля |
| 4 | Pulse Reactor | Hard | длинная секция шара, перевёрнутый куб, ворота корабля |

Все уровни проверены решателем `level_check` (см. ниже) — они проходимы с реакцией 1/30 с.

## Редактор уровней

Главное меню → **EDITOR**. Там список своих уровней (**NEW**, **EDIT**, **DELETE**). Свои уровни
сохраняются в папку `mylevels/` рядом с игрой и появляются в **PLAY** с пометкой CUSTOM.

| Действие | Управление |
|---|---|
| Рисовать / стирать | ЛКМ / ПКМ |
| Инструменты | `1`–`0` или `Q`/`E`: блок, шип, шип вниз, порталы куба/шара/корабля/гравитации/нормальной гравитации, финиш, ластик |
| Прокрутка | `A`/`D`, стрелки (`Shift` — быстрее), колесо мыши, зажатое колесо; `Home`/`End` |
| Отмена | `Ctrl+Z` |
| Сохранить | `Ctrl+S` или кнопка SAVE (при тесте и выходе сохраняется автоматически) |
| Тест-плей | `F5` / `Enter` / кнопка TEST; в тесте `Esc` возвращает в редактор |
| Тема (цвета) | `T` / кнопка THEME |
| Название | клик по полю с именем |

Пунктирная розовая линия — потолок коридора корабля/шара. Уровень сохраняется в том же текстовом
формате, что и официальные, так что его можно дописать вручную.

### Режимы

Гравитация мягкая, как в Geometry Dash: прыжок куба ~2.2 клетки в высоту и ~0.46 с в воздухе
(~4.8 клетки по горизонтали). Все значения — в `src/config.h`.

* **Куб** — прыжок только с поверхности; удержание кнопки = автопрыжок при приземлении.
  В воздухе куб вращается, на земле угол доводится до ближайших 90°.
* **Шар** — нажатие на поверхности инвертирует гравитацию, шар перекатывается на потолок и обратно.
* **Корабль** — удержание = ускорение вверх, отпускание = вниз; вертикальная скорость ограничена,
  корпус наклоняется по скорости. Показываются пол и потолок коридора.

Смерть — касание шипа или удар боковой гранью блока (куб и шар также погибают при ударе
«головой» о низ блока; корабль скользит). На верхнюю грань можно приземляться.

## Структура кода

```
src/
  main.cpp          точка входа
  config.h          enum PlayerMode и все константы физики/камеры — крутите здесь
  Game.h/.cpp       машина состояний, цикл с фиксированным шагом 240 Гц, рендер мира, HUD, частицы
  Player.h/.cpp     физика куба, шара и корабля
  Level.h/.cpp      загрузка текстового уровня, порталы, отрисовка объектов
  Collision.h/.cpp  хитбоксы и запросы к сетке
  IconRenderer.*    8 кубов, 8 шаров, 8 кораблей (каждая иконка — своя функция) и палитра из 12 цветов
  Editor.*          встроенный редактор уровней
  Menu.*, UI.*      экраны меню и простые виджеты
  Settings.*        settings.txt (key=value)
tools/level_check.cpp  консольный решатель: проверяет, что уровень проходим
levels/             уровни
```

Физика идёт фиксированными шагами (`cfg::PHYSICS_HZ = 240`) через аккумулятор, рендер
интерполирует позицию между шагами, так что поведение не зависит от FPS.

## Как создать свой уровень

Положите `.txt`-файл в `levels/` — он появится в меню выбора уровня (сортировка по имени файла;
имя файла без расширения — ключ рекорда в `settings.txt`).

```
// комментарий
@name My Level        название в меню
@difficulty Hard      метка сложности: Easy / Normal / Hard / Insane (необязательно)
@bg 40 90 200         цвет фона (RGB)
@ground 30 70 170     цвет пола/блоков
................................................
..........................................#.....
.......^.......###.....^^.....S.....#.....#...E.
```

| Символ | Объект |
|---|---|
| `.` или пробел | пусто |
| `#` | блок (на верх можно встать, бок убивает) |
| `^` / `v` | шип вверх / шип вниз (висит на верхней грани клетки) |
| `C` `B` `S` | порталы куба, шара, корабля |
| `G` | портал инверсии гравитации (переключает) |
| `N` | портал нормальной гравитации |
| `E` | финиш (по X самой левой `E`) |

Правила сетки:

* Клетка — 40×40 px. Последняя строка стоит на полу; пол есть всегда.
* Игрок стартует в колонке 2 на полу и едет вправо со скоростью ~10.4 клетки/с.
  Прыжок куба — ~2.2 клетки в высоту и ~4.8 клетки в длину.
* Коридор корабля/шара (а также перевёрнутого куба) — 10 клеток над полом. В уровне из
  12 строк это строки 2–11; потолок — верхняя грань строки 2.
* Портал из одной буквы занимает 3 клетки по высоте (свою и по одной сверху/снизу).
  Несколько одинаковых букв друг под другом сливаются в один высокий портал — удобно, чтобы
  игрок не «промахнулся» мимо портала в коридоре (`C` в строках 3–10 закрывает весь коридор).
* Каждый портал срабатывает один раз за попытку.

### Проверка проходимости

```bash
cmake -S . -B build -DGEOMETRY_RUSH_BUILD_TOOLS=ON
cmake --build build --target level_check
./build/level_check levels/*.txt          # --path выведет найденную последовательность нажатий
```

`level_check` перебирает все варианты «держать/отпустить» с шагом 1/60 с и 1/30 с на той же
физике, что и игра, и сообщает, проходим ли уровень, а также насколько далеко уходят
тривиальные стратегии («ничего не нажимать», «всё время держать»).

# Flight Sim — 3D-симулятор самолёта

В том же репозитории есть второй исполняемый файл — **`FlightSim`**: 3D-симулятор лёгкого
двухдвигательного реактивного самолёта (класс бизнес-джета, 7.6 т) с физикой, близкой к реальной,
и системой предупреждений как в настоящей кабине. Собирается той же командой, что и игра:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release -j
./build/FlightSim               # Windows: build\Release\FlightSim.exe
```

## Что моделируется

* **Динамика с 6 степенями свободы**: силы и моменты в связанных осях, тензор инерции,
  гироскопические члены, кватернион ориентации, фиксированный шаг 240 Гц.
* **Аэродинамика**: подъёмная сила по углу атаки с **сваливанием** (срыв, сваливание на крыло,
  потеря демпфирования крена → вход в штопор), индуктивное сопротивление, **влияние земли**,
  волновой кризис после M 0.72, скольжение, устойчивость по курсу и поперечная (V-образность),
  обратный момент рыскания от элеронов, демпфирование по угловым скоростям.
* **Органы управления с рулевыми машинками**: рули отклоняются с конечной скоростью,
  эффективность растёт с квадратом скорости — на малой скорости самолёт «вялый».
  Нужен **триммер**: без него самолёт держит свою балансировочную скорость и раскачивается фугоидой.
* **Двигатели**: обороты N1 с инерцией раскрутки (на малом газе — медленно), тяга падает с высотой
  и скоростью, двигатели выше центра масс — прибавка газа опускает нос.
* **Механизация и шасси**: закрылки 0/10/20/35° (выпускаются ~2.5°/с), интерцепторы,
  шасси с циклом 6 с и блокировкой уборки на земле, амортизаторы, управляемая носовая стойка,
  тормоза и стояночный тормоз, трение качения/боковое.
* **Атмосфера ISA**: плотность и скорость звука по высоте, приборная (IAS) и истинная (TAS) скорость.
* **Ветер**: штиль, 270/10, боковой 360/15 с порывами до 25, болтанка (`F8`).
* **Мир**: процедурный остров 41×41 км с горами, побережьем и морем; аэродром с ВПП 09/27
  (2600 м), разметкой, огнями приближения, **PAPI**, ветроуказателем, вышкой и ангарами.

## Сигнализация

| Сигнал | Когда | Звук |
|---|---|---|
| **PULL UP! TERRAIN** (красный) | прогноз траектории пересекает рельеф менее чем через 18 с (10 с в посадочной конфигурации) или критическая вертикальная скорость по радиовысоте (GPWS Mode 1) | сирена «whoop-whoop» |
| **TERRAIN** (жёлтый) | столкновение с рельефом по прогнозу через ≤ 35 с | двухтональный сигнал |
| **OVERSPEED** (красный) | приборная скорость выше текущего ограничения: VMO 260 kt, VFE для закрылков 200/180/160 kt, VLE 200 kt для шасси | трещотка (clacker) |
| **BANK ANGLE** (жёлтый) | крен больше 35° в воздухе | двойной сигнал |
| **STALL** (красный) | угол атаки ближе 2° к критическому | тряска штурвала (stick shaker) |
| **SINK RATE** (жёлтый) | большая вертикальная скорость у земли | три коротких сигнала |
| **TOO LOW – GEAR** (жёлтый) | ниже 500 ft со снижением, шасси не выпущено | гудок |

Плюс табло **MASTER WARNING / MASTER CAUTION**, надпись PULL UP на авиагоризонте и красно-чёрная
«пила» ограничения скорости на ленте скорости. Предупреждения о земле отключены на земле и на
заходе на полосу в посадочной конфигурации. Голос GPWS заменён синтезированными тонами
(весь звук генерируется при запуске, внешних файлов нет).

Перегрузка больше +6 / −3 g или скорость выше VMO + 90 kt разрушают планер. Посадка с вертикальной
скоростью больше ~900 fpm ломает шасси; касание законцовкой крыла, фюзеляжем, гондолой
(посадка с убранным шасси) или воды — катастрофа. После касания показывается оценка посадки.

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Штурвал: от себя / на себя | `W`/`S` или `↑`/`↓` | левый стик |
| Крен | `A`/`D` или `←`/`→` | левый стик |
| Педали (руль направления, носовое колесо) | `Q`/`E` | курки / правый стик X |
| РУД больше / меньше | `Shift` / `Ctrl` (удерживать), `PgUp`/`PgDn` | правый стик Y |
| Малый газ / взлётный режим | `Z` / `X` | |
| Триммер нос вниз / вверх | `[` / `]` или `End` / `Home` | крестовина ↑/↓ |
| Закрылки выпустить / убрать | `F` / `V` | бамперы |
| Шасси | `G` | X |
| Тормоза (удерживать) | `Space` или `B` | A |
| Стояночный тормоз | `P` | |
| Интерцепторы | `/` или `K` | B |
| Режим «мышь-штурвал» | `M` (положение мыши = положение штурвала) | |
| Камера: кабина / сзади / снаружи / с вышки | `C` (мышь — обзор, колесо — дистанция) | Y |
| Ветер | `F8` | |
| Справка / пауза / рестарт | `F1` / `Esc` / `R` | Start — пауза |
| Сценарии (в паузе или после аварии) | `1` взлёт · `2` заход ILS · `3` горы | |

С клавиатуры штурвал отклоняется плавно и возвращается в нейтраль сам — как пружинная загрузка.

### Сценарии

1. **Взлёт с ВПП 09**: стояночный тормоз включён, закрылки 10. Снимите тормоз (`P`), полный газ
   (`X`), подъём носа на ~110 kt, после отрыва — шасси (`G`), на 150+ kt закрылки убрать.
2. **Заход по ILS на ВПП 09**: 6 миль до торца на глиссаде 3°, закрылки 20, шасси выпущено,
   самолёт сбалансирован. Курс и глиссада — пурпурные ромбы на PFD, плюс PAPI у полосы
   (2 белых + 2 красных = на глиссаде). Закрылки 35, ~120 kt, у земли — малый газ и выравнивание.
3. **Горы**: на 220 kt в направлении самой высокой вершины острова — проверка TERRAIN / PULL UP.

### Приборы

* **PFD**: авиагоризонт со шкалой крена и индикатором скольжения, лента скорости с трендом за 10 с,
  зонами сваливания и ограничения, число M, лента высоты с отметкой земли, вариометр,
  лента курса с путевым углом, радиовысота ниже 2500 ft, ILS (курс/глиссада, DME).
* **Двигатель и конфигурация**: N1 с отметкой режима РУД, рычаг РУД, закрылки (рычаг и
  фактическое положение), триммер, лампы шасси (зелёные — выпущено и на замках, красные — в движении),
  табло тормозов и интерцепторов, положение штурвала/педалей и фактические отклонения рулей,
  угол атаки, перегрузка, TAS, путевая скорость, время до столкновения с рельефом.
* **В кабине** — проекция на стекло (HUD): линия горизонта, шкала тангажа, вектор скорости.
