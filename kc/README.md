# kc — маленький компилируемый язык с C-подобным синтаксисом

Компилятор написан на Rust: `kc` → ассемблер x86-64 (NASM) → `nasm` + `ld` → статический ELF для Linux.
Без libc: весь ввод-вывод идёт через системные вызовы.

```sh
cargo build --release
./target/release/kc examples/demo.kc -o demo && ./demo
./target/release/kc examples/tests.kc -o tests && ./tests   # самопроверка, код возврата = число провалов
```

Флаги: `-o файл` — имя результата (по умолчанию `a.out`), `-S` — только записать `.asm`, `--keep` — не удалять `.asm`/`.o`.
Нужны `nasm` и `ld` (binutils).

## Модель данных

Тип один — `int`, 64-битное знаковое целое. Указатель, адрес строки, адрес массива — это тоже просто `int`.
Память адресуется двумя способами:

| Запись | Смысл |
|---|---|
| `*p` | 8 байт по адресу `p` |
| `p[i]` | то же, что `*(p + i*8)` — элемент размером 8 байт |
| `load8(p)` / `store8(p, v)` | один байт (для строк) |
| `&x`, `&a[i]` | адрес переменной / элемента |

## Программа

На верхнем уровне — только функции и глобальные переменные. Точка входа — `int main()`, её результат становится кодом возврата процесса.

```c
int counter = 0;            // глобальная переменная (инициализатор — константа или строка)
int msg = "hello";          // глобальный указатель на строку
int table[4] = {1, 2, 3};   // глобальный массив, хвост заполняется нулями
int zeros[100];             // массив из нулей

int add(int a, int b) { return a + b; }   // до 6 параметров, все int
void hello() { println(msg); }           // void = функция, возвращающая 0

int main() { return add(2, 3); }
```

## Переменные и массивы

```c
int x;                  // 0
int y = x + 1, z = 2;   // несколько объявлений через запятую
int a[5];               // локальный массив из 5 элементов, обнулён
int b[] = {1, 2, 3};    // размер берётся из инициализатора
int p = alloc(8 * 10);  // «куча»: 80 байт через mmap
p[3] = 42;
```

Имя массива вычисляется в его адрес (как в C), поэтому массив можно передать в функцию: `sum(a, 5)`.
Присвоить массиву нельзя (`a = ...` — ошибка). Видимость переменных — блочная, `{ ... }` открывает новую область.

## Операторы

По убыванию приоритета:

| Операторы | |
|---|---|
| `a[i]` `f(x)` `x++` `x--` | постфиксные |
| `-x` `+x` `!x` `~x` `*p` `&x` `++x` `--x` | унарные |
| `*` `/` `%` | |
| `+` `-` | |
| `<<` `>>` | `>>` — арифметический сдвиг |
| `<` `<=` `>` `>=` | |
| `==` `!=` | |
| `&` | |
| `^` | |
| `\|` | |
| `&&` | короткое вычисление |
| `\|\|` | короткое вычисление |
| `c ? a : b` | тернарный, справа налево |
| `=` `+=` `-=` `*=` `/=` `%=` `&=` `\|=` `^=` `<<=` `>>=` | присваивание, справа налево |

Сравнения и логические операторы дают `0` или `1`. Ложь — это `0`, всё остальное — истина.
`x++` возвращает старое значение, `++x` — новое.

## Управление

```c
if (x > 0) { ... } else if (x < 0) { ... } else { ... }
while (cond) { ... }
do { ... } while (cond);
for (int i = 0; i < n; i++) { ... }   // любая из трёх частей может отсутствовать
break; continue; return; return expr;
```

## Литералы и комментарии

- числа: `42`, `0xFF`; символы: `'a'`, `'\n'` (это просто число);
- строки: `"text\n"` — указатель на байты с нулём на конце; строки изменяемы;
- escape: `\n \t \r \0 \e \\ \" \' \xNN`;
- комментарии: `// ...` и `/* ... */`.

## Встроенные функции

Встроены в компилятор: `syscall(nr, a1..a6)`, `load8(addr)`, `store8(addr, byte)`.

Стандартная библиотека (написана на самом kc, см. `PRELUDE` в `src/main.rs`):

| Функция | |
|---|---|
| `print(s)`, `println(s)` | вывести строку (с переводом строки) |
| `putchar(c)`, `print_int(n)` | символ / число |
| `write(fd, buf, len)`, `read(fd, buf, len)` | системные вызовы |
| `strlen(s)`, `strcmp(a, b)` | строки |
| `memset(p, byte, n)`, `memcpy(dst, src, n)` | побайтовые операции с памятью |
| `alloc(n)`, `free(p, n)` | выделение/освобождение памяти (mmap/munmap) |
| `abs(n)`, `exit(code)` | |

Эти имена заняты — свою функцию с таким именем объявить нельзя.
